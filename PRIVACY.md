# Privacy Policy

This extension does not collect, store, or transmit any user data.

The only information persisted is a local on/off preference for dark mode,
stored via `chrome.storage.local` on the user's own device. This preference
never leaves the device and is not shared with the extension author or any
third party.

The extension does not read, record, or transmit page content, trading data,
account information, browsing history, or any other personal information.
