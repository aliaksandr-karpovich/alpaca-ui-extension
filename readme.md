This is a small chrome extension with some small UI improvements to https://app.alpaca.markets website.

## Installation
1. Clone this repo 
2. open chrome://extensions/
3. Enable developer mode
4. load unpacked and select the cloned repo directory

Current set of features:
- Fixed table width on /account/positions page for large screens
- Dark mode
- Portfolio chart on the dashboard skips market-closed gaps (nights, weekends): each data point gets equal width
